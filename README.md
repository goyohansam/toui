# 토의도우미 (Firebase 버전, PRD v0.3)

모둠 토의의 8단계 순서, 역할별 할 말, 타이머·발언 구슬·별 평가를 안내하는 수업용 웹앱입니다.
같은 폴더 위의 `Code.gs` 등은 예전 구글 시트 버전이고, **이 `firebase/` 폴더가 새 버전**입니다.

## 폴더 구성

| 위치 | 하는 일 |
|---|---|
| `public/index.html` | 학생 화면 |
| `public/teacher.html` | 선생님 화면 (조종판, 현황판, 토의방 열기, 별 확정, 학급 관리, 누적 보기, 설정) |
| `public/board.html` | 전자칠판용 '칠판 보기' |
| `public/demo.html` | 체험판: 선생님 + 학생 3명 화면을 한 번에 띄워 연습 |
| `public/js/config.js` | **Firebase 연결 정보를 넣는 곳** (비워 두면 체험판으로 열림) |
| `firestore.rules` | 보안 규칙 (콘솔에 붙여 넣어 게시) |
| `.github/workflows/deploy.yml` | GitHub에 올리면 GitHub Pages로 자동 배포 |

## 1. 먼저 체험판으로 써 보기 (설치 없이)

터미널에서 아래를 실행한 뒤 브라우저에서 `http://localhost:8000/demo.html` 을 엽니다.

```bash
cd public && python3 -m http.server 8000
```

- 왼쪽 선생님 화면에서 **토의방 열기 → 주제 입력 → 🚀 토의방 열기**를 누르면 학생 3명 화면이 바로 바뀝니다.
- 체험판 자료는 이 컴퓨터의 브라우저 안에만 저장됩니다. 학생 핀은 모두 `1234` 입니다.
- 화면 위 '체험 데이터 지우고 처음부터'로 초기화할 수 있습니다.

## 2. 실제 주소 (배포됨)

| 누가 | 주소 |
|---|---|
| 학생 | https://goyohansam.github.io/toui/ |
| 선생님 | https://goyohansam.github.io/toui/teacher.html |
| 전자칠판 | 선생님 화면 오른쪽 위 **🖥 칠판 보기** |

- 데이터는 Firebase 프로젝트 `toui-helper`(Firestore 서울, 무료 요금제)에 저장됩니다.
- 화면 파일은 GitHub 저장소 `goyohansam/toui`의 `public/` 폴더이고, `main` 브랜치에 올리면 GitHub Pages로 자동 배포됩니다.
- 선생님 화면에서 구글 로그인 → **학급 관리**에서 학생을 등록합니다. (한 줄에 `번호 이름 핀 모둠`)

## 3. 관리할 때 알아둘 것

- **교사 계정 바꾸기/추가**: Firebase 콘솔 → Firestore Database → 데이터 → `admins` 컬렉션에
  교사 구글 계정 주소를 문서 ID로 하는 문서를 추가합니다. (저장소에는 계정 주소를 적지 않습니다)
- **보안 규칙을 고쳤을 때**: `firestore.rules` 내용을 콘솔 → Firestore Database → 규칙 탭에 붙여 넣고 **게시**해야 반영됩니다. (자동 배포되지 않음)
- **주소가 바뀌면**: Firebase 콘솔 → Authentication → 설정 → 승인된 도메인에 새 주소를 추가해야 교사 구글 로그인이 됩니다.
- 학생 이름과 핀은 저장소에 올리지 않습니다. 선생님 화면에서만 등록하세요.
- `config.js`의 값은 공개되어도 되는 값입니다. 실제 보호는 보안 규칙이 합니다.

## 수업에서 쓰는 순서

1. 선생님: **토의방 열기**에서 주제·시간·진행 방식을 정하고 연다. (역할은 토의마다 자동으로 돌아감)
2. 학생: 이름 → 핀 → **토의 시작하기**.
3. 선생님: 조종판에서 **다음 ▶**으로 단계를 넘긴다. (익숙해지면 '모둠별 진행'으로 바꿔 이끔이가 넘김)
4. 7단계가 끝나면 **별 확정** 탭에서 모둠별로 확인하고 **확정** → 학생 화면에 결과가 열린다.
5. **누적 보기**에서 점수·역할 이력을 보고 CSV로 내려받는다.

## PRD와 다르게 만든 점 / 알아둘 점

- **Vite 빌드를 쓰지 않았습니다.** 이 컴퓨터에 Node가 없어, 빌드 없이 그대로 올리면 도는 구조(브라우저 모듈 + Firebase SDK를 CDN에서 불러옴)로 만들었습니다. 동작은 같습니다.
- **Firebase 프로젝트 `toui-helper`에 연결되어 있습니다** (2026-11-21, Firestore 서울, 무료 요금제). 교사 로그인, 학생 핀 로그인, 쪽지·차례·타이머·구슬·스티커·별 평가·교사 확정, 그리고 권한(남의 점수·핀·다른 모둠 읽기 거부 등)을 실제 연결 상태에서 시험했습니다. PRD의 Firebase Hosting 대신 GitHub Pages로 배포했습니다(비밀 키 등록이 필요 없어서).
- 체험판은 주소 뒤에 `?demo`를 붙이거나 `demo.html`로 엽니다.
- 3차 범위 중 **보상 설정**과 **모둠 간 결과 비교**는 자리만 있고 비어 있습니다.
- 3명 모둠 외에 결석으로 2명·1명이 되면 역할을 겹쳐서 나눕니다(2명: 이끔이+지킴이 / 기록이+칭찬이).
